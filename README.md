# misc-tools

![](./assets/logo.svg)

misc-toolsはツール群である。

## 使う

- [Webアプリケーションを使う](https://dist.kkawahara.net/development/misc-tools/)
- [デスクトップアプリケーションを使う](https://github.com/kkawaharanet/misc-tools/releases)

## 開発する

```bash
# 開発サーバーを起動する
$ npm i --legacy-peer-deps
$ npm run dev

# Webアプリケーションをビルドする
$ npm run build

# デスクトップアプリケーションをビルドする
$ npm run build:tauri
```
